# Security policy

## Website reports

Report a suspected vulnerability privately through the
[CrowFlix security-advisory form](https://github.com/CrowLoki/Crow-Flix/security/advisories/new).
Do not place exploit details, credentials, private URLs, personal data, or
tokens in a public issue.

For website reports, include the affected URL, browser, observed security
impact, and minimal reproduction steps. For desktop-application reports, use
the fuller policy in the CrowFlix source repository.

The official website never asks for playlist credentials, subscription login
details, payment information, or an application password. Its Windows download
links go directly to the immutable GitHub release.
