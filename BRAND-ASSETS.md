# Crow-Flix website brand assets

Copyright (C) 2026 Crow.

The website uses the approved CrowFlix visual identity:

- `public/images/crowflix-mascot.png` — approved Crow mascot master.
- `public/images/crowflix-app-preview.png` — official CrowFlix application
  screenshot.
- `public/favicon.png` — approved Crow head favicon.
- `public/assets/fonts/**` — Crow Bitfeather display and mono web fonts.
- `public/assets/cursors/**` — Crow Talon Windows cursor set used with browser
  fallbacks.

The mascot and fonts are byte-identical to the assets distributed in the
official CrowFlix source repository. The complete hashes for every included
asset are in [`ASSET-MANIFEST.sha256`](ASSET-MANIFEST.sha256).
